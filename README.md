# Script Controlled ACL

## Project Description

This project demonstrates Script Controlled Access Control List (ACL) in ServiceNow.

## Features

- Script-based access control
- Controls user access to records
- Uses ACL scripting
- Improves data security
- Demonstrates ServiceNow security configuration

## Technologies Used

- ServiceNow
- JavaScript
- ACL (Access Control List)

## Purpose

The purpose of this project is to understand how Script Controlled ACLs can be used to control access to records and fields in ServiceNow.
